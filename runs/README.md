# runs

Scan output folders, one per `--out` argument. Each holds `results.json` (the
machine-readable record) and `report.html` (the self-contained branded
deliverable).

`self-after-deploy/` is a past scan of rtech-consulting.com, kept as a sample
of the output. It is reference only: a score is a snapshot of a site on its
scan date, not a standing fact.
